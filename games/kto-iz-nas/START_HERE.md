# Start here: «Кто из нас?»

Шумy — набор игр для компании. Ведущий показывает игру на общем экране, остальные входят с телефонов по QR-коду или короткому коду комнаты.

## Запуск локально

```sh
cd games/kto-iz-nas
npm ci
npm start
```

Откройте `http://localhost:5181/tv` на общем экране. Участники подключаются к той же сети и сканируют QR-код или открывают адрес телефона, показанный ведущему.

Подробные правила запуска, игровые режимы и ограничения описаны в [README игры](README.md).
