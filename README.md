# Shumy

Shumy — каталог игр для компании. Ведущий открывает игру на телевизоре или ноутбуке, а остальные подключаются с телефонов по QR-коду.

## Что готово

- Домашняя страница в `site/` — статический вход для игрока и ведущего с локальными SVG-иллюстрациями. Основной текст и действия доступны без JavaScript.
- В приложении `games/kto-iz-nas/` локально доступны 13 режимов: два исходных, десять мини-игр и «Рисуй по словам». Их можно выбрать в лобби ведущего; там же показаны требования к числу игроков. Новые режимы ещё не проверены нагрузочным и устройственным плейтестом и не опубликованы.
- Комнаты разделены короткими кодами. Состояние комнат и записи «Не того дубляжа» хранятся в памяти процесса и пропадают при перезапуске.

## Открыть домашнюю страницу локально

Из корня проекта запусти:

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory site
```

Открой [http://127.0.0.1:8080/](http://127.0.0.1:8080/). Предпросмотр отдаёт только статические файлы домашней страницы; для игр отдельно запусти Node-приложение.

## Запустить игру локально

```sh
cd games/kto-iz-nas
npm ci
npm start
```

Ведущий открывает [http://localhost:5181/tv](http://localhost:5181/tv) и выбирает режим. Игроки в той же Wi-Fi-сети сканируют QR-код с экрана. Правила и параметры запуска описаны в [README игры](games/kto-iz-nas/README.md).
