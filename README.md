# Shumy

Shumy — каталог игр для компании. Ведущий открывает игру на телевизоре или ноутбуке, а остальные подключаются с телефонов по QR-коду.

## Что готово

- Домашняя страница в `site/` на HTML и CSS с локальными SVG-иллюстрациями. В каталоге 12 игр, из которых 10 отмечены «Скоро». Небольшой скрипт анимирует фоновые игровые предметы. Каталог доступен без JavaScript.
- Два доступных режима, «Кто из нас?» и «Рисуй и угадывай», работают в одном приложении из `games/kto-iz-nas/`. Каталог ссылается на существующие публичные экраны. Ведущему нужен пароль, режим выбирается в лобби.
- Система нескольких комнат, вход по короткому коду и генератор аватаров остаются в плане разработки.

## Открыть каталог локально

Из корня проекта запусти:

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory site
```

Открой [http://127.0.0.1:8080/](http://127.0.0.1:8080/). Предпросмотр отдаёт только статические файлы каталога.

## Запустить игру локально

```sh
cd games/kto-iz-nas
npm ci
npm start
```

Ведущий открывает [http://localhost:5181/tv](http://localhost:5181/tv) и выбирает режим. Игроки в той же Wi-Fi-сети сканируют QR-код с экрана. Правила и параметры запуска описаны в [README игры](games/kto-iz-nas/README.md).
